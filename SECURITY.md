# Security policy

tx handles private audio and transcript data. Please report vulnerabilities privately through GitHub's **Report a vulnerability** flow for this repository, if available. If that option is unavailable, contact the maintainer through the GitHub profile without posting exploit details or private data in a public issue.

Include a minimal reproduction with synthetic data, affected version or commit, impact, and any suggested mitigation. Do not attach real recordings, transcripts, tokens, or database files.

The current release is source only and under active development. Security fixes will be assessed against the latest `main` branch; no older release line is currently maintained.
