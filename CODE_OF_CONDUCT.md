# Code of conduct

This project welcomes people who want to improve reliable, privacy aware meeting capture and dictation. Be respectful in issues, pull requests, and discussions. Critique ideas and code without attacking people. Harassment, discriminatory language, threats, and disclosure of someone else's private meeting data are not acceptable.

Maintainers may edit, hide, or remove contributions that violate these expectations and may restrict participation when necessary. If you need to report a conduct concern privately, contact the maintainer through the GitHub profile. For a security vulnerability, follow [SECURITY.md](SECURITY.md).
