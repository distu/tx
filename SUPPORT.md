# Support

- **How do I use tx?** Start with the [README](README.md) and [troubleshooting guide](docs/TROUBLESHOOTING.md).
- **I have a question or idea.** Open a [Discussion](https://github.com/distu/tx/discussions).
- **I found a reproducible bug.** Use the [bug report template](https://github.com/distu/tx/issues/new/choose) with synthetic details.
- **I found a security issue.** Follow [SECURITY.md](SECURITY.md) and report it privately.

Please do not share real recordings, transcripts, participant names, account details, or credentials in public threads.
